## Audit logic notes

- Plan-fit checks compare current declared seats against the selected published tier.
- Same-vendor checks compare declared spend to a lower-priced published tier when it is a defensible alternative.
- Alternative-tool checks compare equivalent capability classes for the selected use case.
- Retail vs credits checks identify when declared retail spend is likely higher than credit-discounted pricing.
